# AI 小说写作工具推荐

整理了 GitHub 上高星标的 AI 小说写作相关开源项目，涵盖通用 LLM 前端、中文小说专用工具、以及创意写作框架等。

## 说明

- 星标数据为大致数值，实际数字可能因时间变化有所不同
- 通用 LLM 前端虽然不是专门为小说写作设计，但配合合适的模型和提示词，同样是非常强大的小说创作工具
- 选择工具时建议根据自身需求考虑：是否需要中文支持、是否需要本地部署、对模型的偏好等
